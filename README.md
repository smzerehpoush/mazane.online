# تابلو

مقایسه‌ی **قیمت و کارمزد** خرید و فروش طلای آب‌شده در سکوهای آنلاین ایران — با
احتساب کارمزد، نه قیمت اسمی. مرجع طراحی: `docs/design/01-architecture.md` و
قراردادهای پیاده‌سازی: `docs/design/02-implementation-conventions.md`.

یک مخزن، دو فرایند:

| مسیر | نقش |
|---|---|
| `collector/` | پایتون ۳.۱۲+ — هر ۳۰ ثانیه قیمت و کارمزد سکوها را می‌خواند، مقدار خام و ضریب را نگه می‌دارد، هزینه‌ی رفت‌وبرگشت را (فقط همین‌جا) محاسبه و در ردیس/پستگرس ذخیره می‌کند |
| `web/` | Next.js (App Router، TypeScript) — فقط می‌خوانَد و رندر می‌کند؛ هیچ فرمولی ندارد |

## پیش‌نیازها

- Python ‏۳.۱۲ یا جدیدتر
- Node.js ‏۱۸.۱۸ یا جدیدتر
- Docker (فقط برای اجرای محلی ردیس و پستگرس؛ تست‌ها به آن نیازی ندارند)

## اجرای محلی

### ۱) سرویس‌های جانبی (ردیس + پستگرس)

```bash
docker compose -f docker-compose.dev.yml up -d
```

مهاجرت `collector/migrations/001_init.sql` در اولین بوت پستگرس خودکار اجرا
می‌شود.

### ۲) گردآورنده

```bash
cd collector
python3 -m venv .venv
.venv/bin/pip install -e ".[dev]"
.venv/bin/tablo-collector
```

هر ۳۰ ثانیه یک نوبت گردآوری انجام می‌شود (فعلاً فقط وال‌گلد). پیکربندی با
متغیر محیطی (پیش‌فرض‌ها با `docker-compose.dev.yml` می‌خوانند):

```
TABLO_REDIS_URL     پیش‌فرض: redis://127.0.0.1:6379/0
TABLO_DATABASE_URL  پیش‌فرض: postgresql://mazane:mazane@127.0.0.1:5432/mazane
```

### ۳) وب

```bash
cd web
npm install
npm run dev
```

سپس <http://localhost:3000> — صفحه‌ی اصلی قیمت و کارمزد خرید و فروش وال‌گلد را با
ارقام فارسی و برچسب «آخرین به‌روزرسانی» نشان می‌دهد. اگر گردآورنده خاموش
باشد صفحه باز هم بالا می‌آید و فقط برچسب زمان کهنه می‌شود (کهنگی، نه خطا).

## تست و تایپ‌چک

تست‌ها **بدون داکر و بدون شبکه** سبز می‌شوند — مرز گردآورنده با فیکسچر
ضبط‌شده و فیک درون‌حافظه‌ای استور، مرز وب با منبع داده‌ی تزریقی:

```bash
# گردآورنده
cd collector
.venv/bin/python -m pytest
.venv/bin/python -m mypy src tests

# وب
cd web
npm test
npm run typecheck
```

## نکته‌ها

- `web-crawler/` کد اختصاصی کارفرماست: کامیت نمی‌شود، کپی نمی‌شود،
  `‎.env.sample`‌اش هرگز باز نمی‌شود (تصمیم ۳، بند ۱۳ سند معماری).
- کرال مؤدب: بازه‌ی ۳۰ ثانیه و
  `User-Agent: TabloBot/0.1 (+https://tablo.gold/about)`.
