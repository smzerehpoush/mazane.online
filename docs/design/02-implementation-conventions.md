# قراردادهای پیاده‌سازی — برای هر عاملی که روی این مخزن کد می‌زند

> مرجع تصمیم‌ها: `docs/design/01-architecture.md` (بند ۱۳ = دفتر تصمیم‌های قطعی).
> مشخصات: مسئله‌ی ۱ گیت‌هاب. بلیت‌ها: مسئله‌های ۲ تا ۱۶ (`gh issue view <n>`).

## چیدمان مخزن

```
collector/   # پایتون ۳.۱۲+ — گردآورنده: آداپترها، نرمال‌سازی، چک میانه، ذخیره
web/         # TanStack Start (SSR با نیترو) + TypeScript — فقط می‌خوانَد و رندر می‌کند
docs/        # اسناد (دست نزنید مگر بلیت بخواهد)
web-crawler/ # مرجع الگو — کد کارفرماست؛ کپی ممنوع، کامیت ممنوع، .env.sample را هرگز باز نکنید
```

## قواعد سخت (نقض = رد کار)

1. **هر مقدار مشتق فقط در گردآورنده محاسبه می‌شود.** وب هیچ فرمولی ندارد.
   تنها فرمول باقی‌مانده: `round_trip = 1 − (1−f_sell)/(1+f_buy)`.
   **قیمت مؤثر وجود ندارد** (سند تصمیم ۰۰۰۲): از هر سکو یک «قیمت» ثبت می‌شود
   — عدد منتشرشده‌ی خودش، یا میانگین دو عددش اگر دو عدد بدهد — و دو کارمزد
   **جدا** کنارش. کارمزد هرگز در قیمت ضرب نمی‌شود؛ `mid × (1 ± f)` از کد
   حذف شده است. سکوی بی‌قیمت در یک نوبت (دفتر سفارشِ یک‌سمته) اصلاً اسنپ‌شات
   نمی‌سازد و کهنه می‌ماند.
2. **`raw_value` و `raw_scale` همیشه ذخیره می‌شوند.** ضریب هر منبع صریح در آداپتر.
3. **چک میانه‌ی تقاطعی:** انحراف >۰٫۵٪ از میانه‌ی سایر منابع ⟸ انتشار نمی‌شود + هشدار در لاگ.
4. **میانگین بین‌سکویی هرگز تولید یا منتشر نمی‌شود.** میانگین دو عددِ *یک*
   سکو این نیست و مجاز است.
5. **قطع منبع ⟸ کهنگی، نه خطا.** صفحه همیشه ۲۰۰ با «آخرین به‌روزرسانی».
6. **کرال مؤدب:** بازه‌ی ۳۰ ثانیه، `User-Agent: TabloBot/0.1 (+https://tablo.gold/about)`،
   احترام به robots.txt. در تست‌ها هیچ تماس شبکه‌ای نیست — فقط فیکسچر.
7. **لینک خروجی درآمدزا بدون `rel="sponsored nofollow noopener"` ممنوع** — تست CI دارد.
8. اندپوینت‌ها و ضریب‌های تأییدشده در `docs/research/01-gold-platforms-and-data-sources.md`.

## مرزهای تست (تنها جاهایی که تست می‌نویسیم)

- **مرز گردآورنده:** payload فیکسچر ⟸ ردیف‌های ذخیره‌شده در استور. pytest.
- **مرز وب:** استور seed شده ⟸ خروجی رندرشده (HTML/پاسخ). vitest.
- تست رفتار بیرونی، نه جزئیات پیاده‌سازی. تست‌ها بدون داکر و سرویس زنده سبز می‌شوند:
  لایه‌ی ذخیره پشت اینترفیس کوچک است و تست‌ها فیک درون-حافظه‌ای همان اینترفیس را می‌گیرند.

## استک و ابزار

- **collector:** httpx (async)، pydantic v2، asyncpg (پستگرس)، redis-py؛ pytest + pytest-asyncio؛
  `pyproject.toml` با نصب `pip install -e ".[dev]"`؛ تایپ‌چک: `mypy` (پیکربندی آسان‌گیر).
- **web:** TanStack Start (رندر سمت سرور با نیترو، پریست `node-server`؛ TypeScript strict)،
  Tailwind + shadcn/ui، vitest؛ تایپ‌چک: `tsc --noEmit`.
  ⚠️ **قاعده‌ی باندل:** منطق سروری (ioredis، pg، متغیرهای محیط) فقط زیر `src/lib/server/`؛
  کامپوننت‌ها هرگز مستقیم از آن import نمی‌کنند — از راه `createServerFn` یا loader مسیر.
  پلاگین import-protection تنکستک نقضش را در بیلد می‌شکند، نه در زمان اجرا.
- Postgres 16 و Redis 7 (هم‌نسخه با سرور). `docker-compose.dev.yml` برای اجرای محلی؛ تست‌ها به آن وابسته نیستند.
- UI فارسی و راست‌به‌چپ؛ ارقام نمایش با `Intl.NumberFormat('fa-IR')`؛ ارقام لاتین در JSON-LD و URL.
- `normalizeFa()` روی مرز هر ورودی متنی فارسی.

## گردش کار عامل

- بلیتت را با `gh issue view <n>` بخوان؛ معیارهای پذیرش، تعریف «تمام» هستند.
- قرمز-سبز در مرزهای بالا؛ تایپ‌چک و تست‌های مرتبط را قبل از پایان اجرا کن.
- فرمان‌های شبکه‌ای (نصب بسته) در سندباکس ممکن است بسته باشند — از گزینه‌ی خروج از سندباکس Bash استفاده کن.
- **هیچ فرمان git اجرا نکن** — کامیت با هماهنگ‌کننده است.
- خروجی پایانی: خلاصه‌ی کار، فایل‌های تغییرکرده، خروجی تست/تایپ‌چک.
